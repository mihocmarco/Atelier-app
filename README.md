# Atelier

A personal web app for organizing electronics and Arduino projects. Save each project with photos, video, notes and code, all synced between your phone and laptop. It can be added to your phone's home screen and used like a regular app (PWA).

## Features

- Personal accounts: everyone signs up for their own account and only sees their own projects
- Projects with a title, status (idea / in progress / done / archived) and tags
- Photos and video: take a photo, record a video, or pick from the gallery
- Fields for notes and code, with a copy button
- Search by title, tag or description, plus filtering by status
- Real-time sync across devices
- Dark theme with blue accents and a circuit board background

## Tech stack

- React + Vite
- Firebase Authentication and Firestore (accounts and database)
- Cloudinary (photo and video storage)
- Vercel (hosting)
